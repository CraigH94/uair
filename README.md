# Uair

A light, local-only time tracker and timesheet for macOS, on the Mac App Store.

This repository holds Uair's website, published with GitHub Pages:

- [Support](https://craigh94.github.io/uair/support.html)
- [Privacy Policy](https://craigh94.github.io/uair/privacy.html)

To report a problem, ask a question or suggest a feature, [open an issue](https://github.com/CraigH94/uair/issues).
Please include your macOS version and Uair version (Uair → About Uair). Issues are public, so don't post personal
information or attach your data file or timesheets.

The app's source code isn't here.
